    Worksheet 9 Mathematical Expectation (2.2)
    

    One of the most important concepts in probability theory is the expected value of a random variable. One can think of expected value as follows: If we perform an experiment numerous times, the “average” result is the expected value (arithmetic mean).
    🔗

    1.

    Suppose we flip a fair coin and let \(X=1\) if a heads appears and \(X=0\) if tails. What does your intuition tell you the “expected” value of \(X\) should be if the coin is flipped repeatedly?
    🔗
    🔗

    Definition 9.1. Expected Value (B:2.2-1).

    If \(X\) is a discrete random variable, having a probability mass function \(f(x)\) and space \(S\text{,}\) and \(u(X)\) is any function on \(X\text{,}\) so that \(\sum_{x \in S} u(x) f(x)\) exists, then expected value or mathematical expectation of \(u(X)\text{,}\) denoted \(E[u(X)],\) is
    🔗
    \begin{equation*} E[u(X)] = \sum_{x \in S} u(x) f(x) \end{equation*}
    🔗
    🔗

    Theorem 9.2. Properties of Expected Value (B:2.2-1).

    If the mathematical expectation \(E\) exists, then it satisfies the following properties:
    🔗
    1. \(E(c) = c\) where \(c\) is a constant
      🔗
      🔗
    2. If \(X\) is a discrete random variable and \(c\) is a constant, then \(E[cu(X)] = cE[u(X)].\)
      🔗
      🔗
    3. If \(c_{1}\) and \(c_{2}\) are constants and \(u_{1}\) and \(u_{2}\) are functions of \(X\text{,}\) then
      \begin{equation*} E[(c_{1}u_{1}(X) + c_{2}u_{2}(X)] = c_{1}E[u_{1}(X)]+c_{2}E[u_{2}(X)]. \end{equation*}
      🔗
      🔗
