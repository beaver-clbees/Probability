    The conditional probability of an event \(A\text{,}\) given that event \(B\) has occurred, is defined by
    🔗
    🔗
    🔗
    Note: If \(P(B) \gt 0\text{,}\) then
    1. \(\displaystyle P(A\mid B) \geq 0\)
      🔗
      🔗
    2. \(\displaystyle P(B\mid B) = 1\)
      🔗
      🔗
    3. If \(A_{1},A_{2},...,A_{k}\) are disjoint, then \(P((A_{1} \cup A_{2} \cup \cdots \cup A_{k}) \mid B) = P(A_{1} \mid B) + P(A_{2} \mid B) + \cdots + P(A_{k} \mid B)\text{.}\)
      🔗
      🔗
    In other words, \(P(A\mid B)\) satisfies all of the rules of a probability function.
