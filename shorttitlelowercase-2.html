    Definition 1.3. Event.

    An event is a collection of outcomes in a sample space.
    🔗
    🔗
    Notice that a sample space S is a set, and an event is a subset of S. We will review some basics of sets and see how they can be represented with Venn Diagrams. Our universal set is always our sample space in this context because the sample space contains all possible outcomes. We will assume all sets and elements are in S.
    🔗

    \(\emptyset\) denotes the empty or null set (the set containing no elements).

    These definitions extend to larger numbers of subsets. For example, given \(A_1,A_2,...,A_k \subseteq S\)
    1. \(A_1, A_2,...,A_k\) are mutually exclusive events if \(A_i \cap A_j = \emptyset\) for \(i \neq j\) (they are pairwise disjoint).
      🔗
      🔗
    2. \(A_1, A_2,...,A_k\) are exhaustive events if \(A_1 \cup A_2 \cup \cdots \cup A_k=S\)
