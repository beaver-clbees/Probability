    Definition 8.1. Random Variable Definition (2.1-1).

    Let \(S\) be the sample space for a random experiment. A function \(X\) that assigns to each \(s \in S\) exactly one real number \(X(s)=x\) is called a Random Variable (RV). The space of \(X\) is the set of real numbers \(\{x\mid X(s)=x, s \in S\}\text{.}\)
    🔗
    🔗
    Notation: Typically, we use capital letters to denote random variables and lower case letters to denote a value the random variable can take on. For example, \(X\) is a random variable and \(x\) is a value of \(X\text{.}\)
    🔗

    1.

    Example: Three balls are randomly chosen without replacement from an urn containing \(3\) white, \(3\) red, and \(5\) black balls.
    🔗
    🔗

    Definition 8.2.

    Let \(X\) be a random variable with one-dimensional space \(S\) where \(S\) is a subset of the real numbers. If \(S\) contains a countable number of points (this means we can list them out in an order, or equivalently put them into a one-to-one correspondence with the positive integers) then we say \(X\) is a random variable of the type, or that \(X\) is a random variable.
    🔗
    🔗
    Note that now we are calling \(S\) the space for the random variable \(X\text{.}\) In other words we will just think about the sample space in terms of the possible outcomes for \(X\text{,}\) the measurement under consideration.
    🔗
